The tests directory coverage is at 97%, not 97.66%. I've analyzed the missing coverage and found it falls into these categories:

**Uncovered Code Breakdown:**

1. **Error-handling branches in parametrized tests** (~35 lines): Test functions have `if isinstance(expectation, Exception):` blocks to handle error test cases, but none of the current parametrized test cases actually test error conditions. Files affected:
   - `test_parameter_types.py`: 14 lines (82% coverage)
   - `test_calibrators.py`: 6 lines (90% coverage)
   - `test_validation.py`: 12 lines (93% coverage)
   - `test_encodings.py`: 4 lines (94% coverage)
   - `test_comparisons.py`: 2 lines (96% coverage)
   - `test_definitions.py`: 3 lines (98% coverage)

2. **Unused test fixture** (1 line): `clarreo_test_data_dir` in `conftest.py` is defined but never used (no CLARREO test data exists)

3. **Benchmark helper functions** (4 lines): Nested setup/wrapper functions in `test_slow_benchmarks.py` and internal mock classes in `test_validation.py`

4. **Other test helpers** (2 lines): Helper methods and test utilities in `test_common.py` and `test_suda_parsing.py`

**Recommendation**: The 99% threshold is working as intended - it's detecting that test infrastructure code exists but isn't being exercised. To reach 99%, we'd need to either:
- Add error test cases to parametrized tests
- Remove the unused `clarreo_test_data_dir` fixture
- Add `# pragma: no cover` to legitimately uncoverable lines

This is test infrastructure, not production code, so the current 97% may be acceptable. The threshold will catch if actual test code stops running.
