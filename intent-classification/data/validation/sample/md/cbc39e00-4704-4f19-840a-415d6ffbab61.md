- Eliminates coupling between ApplicationMainLoop and View hierarchy
- Cursor management co-located with focus management
- ApplicationMainLoop.SetCursor() delegates to ApplicationNavigation.UpdateCursor()

#### 5. Fixed cursor viewport clipping bug
- **Issue**: When a view's viewport is smaller than its content area and a subview has cursor visible outside the viewport, the cursor incorrectly shows (e.g., resizing a Dialog smaller causes TextField cursor to remain visible outside Dialog bounds)
- **Root Cause**: ApplicationNavigation.UpdateCursor() only checked if cursor position was valid from the focused view's perspective, not if it was within all ancestor viewports
- **Fix**: UpdateCursor() now walks up the view hierarchy checking each ancestor's viewport bounds using ViewportToScreen coordinates
- **Result**: Cursor is now properly hidden when positioned outside any ancestor viewport

Created design document at `/cursor-class-design.md` exploring a unified `Cursor` class.

**Key proposals**:

1. **New `CursorShape` enum** replacing `CursorVisibility` - based on ANSI DECSCUSR values (0-6) instead of Windows hex encoding:
   - `Hidden`, `BlinkingBlock`, `SteadyBlock`, `BlinkingUnderline`, `SteadyUnderline`, `BlinkingBar`, `SteadyBar`
   - Directly maps to ANSI terminal sequences
   - Drivers handle platform-specific conversion

2. **`Cursor` record class** consolidating position + shape:
   - Immutable value type with `Position`, `Shape`, and `CoordinateSystem` properties
   - Factory methods: `Cursor.ContentArea()`, `Cursor.Viewport()`, `Cursor.Screen()`, `Cursor.Hidden`
   - Built-in `ToScreen(View)` conversion with viewport clipping
   - No more null-vs-Invisible confusion

3. **Updated APIs**:
   - `View.SetCursor(Cursor cursor)` replaces `SetCursor(Point?, CursorVisibility)`
   - `IOutput.SetCursorShape(CursorShape)` replaces `SetCursorVisibility(CursorVisibility)`
   - Explicit coordinate system tracking prevents bugs

**Benefits**: Type safety, ANSI-first design, clearer API, built-in coordinate conversion, eliminates split state management.

Document includes migration strategy, code examples, and open questions for discussion.
