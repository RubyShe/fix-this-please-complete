Split subsurface scattering rendering into separate steps, add Fresnel effect, and implement 2x2 box blur anti-aliasing

<pr_description>
## Overview

This PR refactors the subsurface scattering rendering pipeline to separate concerns and adds new visual enhancement features including Fresnel effect and final anti-aliasing.

## Changes

### 1. Separated Subsurface Scattering Rendering

**Before:** The `subsurface.fs` shader performed two operations in a single pass:
- Subsurface scattering calculations (light scattering and glow effects)
- Merging with `_objectTextureSmall`

**After:** These are now split into two distinct rendering steps:
- **Subsurface Scatter Shader** (`subsurface_scatter.fs`) - Performs only the subsurface scattering calculations
- **Merge Shader** (`merge.fs`) - Performs only the final merge operation

### 2. New Fresnel Effect

Implemented a new Fresnel effect shader (`fresnel.fs`) that is applied **after** subsurface scattering but **before** merging with `_objectTextureSmall`. The Fresnel effect:
- Uses edge detection via a Sobel-like gradient operator to identify boundaries
- Enhances edges with subtle highlights (30% intensity, modulated by thickness)
- Adds realistic light reflection at viewing angles
- Creates more visually appealing and physically accurate rendering

### 3. Split Object Shader

**Before:** The `_objectShader` used a `smoothCircles` uniform to switch between two rendering modes.

**After:** Split into two dedicated shaders without the uniform:
- **Background Object Shader** (`background_object.fs`) - Simple cosine falloff for alpha (background rendering)
- **Foreground Object Shader** (`foreground_object.fs`) - Smooth circles with angle-based factor (foreground rendering)

Both shaders share the same VBO for efficiency while maintaining separate VAOs.

### 4. Zoom-Adaptive Effect Scaling

Added zoom-adaptive scaling to ensure visual effects remain consistent across different zoom levels:
- **Subsurface Scattering**: Scatter radius scales with `zoomScale = max(0.5, min(2.0, 5.0 / zoom))`
- **Fresnel Effect**: Edge detection kernel and intensity scale with zoom
- **Result**: Effects are visible at high zoom (close-up) and not overly dominant at low zoom (far away)

### 5. Final Anti-Aliasing with 2x2 Box Blur

Implemented a final rendering step that applies a 2x2 box filter (averaging) before output to screen:
- **Box Blur Shader** (`box_blur.fs`) - Samples each pixel and its 3 neighbors (forming a 2x2 grid)
- Calculates simple average: `(sample1 + sample2 + sample3 + sample4) * 0.25`
- Provides subtle anti-aliasing and smoothing across the entire rendered image
- Reduces jagged edges for a softer, more polished final appearance

### Rendering Pipeline

```
Metaballs Output 
    ↓
Subsurface Scatter Shader (subsurface_scatter.fs) [zoom-scaled]
    ↓
Fresnel Effect Shader (fresnel.fs) [zoom-scaled] ← NEW
    ↓
Merge Shader (merge.fs)
    ↓
2x2 Box Blur Averaging (box_blur.fs) ← NEW
    ↓
Final Output
```

- `resources/subsurface_scatter.fs` / `.vs` - Isolated subsurface scattering logic with zoom scaling
- `resources/fresnel.fs` / `.vs` - Edge-based Fresnel effect implementation with zoom scaling
- `resources/merge.fs` / `.vs` - Simple blend operation with objectTextureSmall
- `resources/background_object.fs` - Background object rendering (replaces smoothCircles=false)

- `resources/box_blur.fs` / `.vs` - 2x2 box filter for final anti-aliasing

### Code Changes
