- Allows manual duration input if estimation is incorrect
- Validates against remaining recording time to prevent overflow

- **Duration Overflow**: Prevents adding segments that exceed recording limits

- **File Storage Errors**: Graceful error recovery with user notification
- **Unsupported Formats**: Clear feedback for invalid file types
