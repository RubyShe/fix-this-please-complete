<pr_description>
## Summary

Implemented insert rows functionality for fulltext indexed tables as requested.

## Changes Made

### 1. Query Optimizer Layer (`ydb/core/kqp/opt/physical/effects/kqp_opt_phy_insert_index.cpp`)
- ✅ Added `MakeInsertFulltextIndexRows` function that builds a lambda to:
  - Read fulltext index settings from `TIndexDescription`
  - Extract text from input rows
  - Call `FulltextAnalyze` callable to tokenize text according to index settings
  - Generate index rows with structure: `(token, primary_key_columns..., data_columns...)`
- ✅ Integrated into `KqpBuildInsertIndexStages` to handle `GlobalFulltext` index type
- ✅ Properly handles both covered and non-covered index columns

### 2. MKQL Compiler Layer (`ydb/core/kqp/query_compiler/kqp_mkql_compiler.cpp`)
- ✅ Added `FulltextAnalyze` callable that calls `TKqpProgramBuilder::FulltextAnalyze`
- ✅ Properly passes text and serialized analyzer settings to runtime layer

### 3. Runtime Layer (`ydb/core/kqp/runtime/`)
- ✅ Implemented `TKqpProgramBuilder::FulltextAnalyze` method in `kqp_program_builder.{cpp,h}`
- ✅ Creates `FulltextTokenize` callable using `TCallableBuilder`
- ✅ Validates input types (text and settings must be strings)
- ✅ Returns `List<String>` type
- ✅ Created `kqp_fulltext_tokenize.cpp/h` with `TFulltextTokenizeWrapper` computation node
- ✅ Deserializes `Ydb::Table::FulltextIndexSettings::Analyzers` from settings parameter
- ✅ Calls `NKikimr::NFulltext::Analyze` function (same as used by `TBuildFulltextIndexScan`)
- ✅ Returns list of tokens as `TUnboxedValue`
- ✅ Registered in `GetKqpBaseComputeFactory` in `kqp_compute.cpp`
- ✅ Added to `ya.make` build configuration

### 4. Tests (`ydb/core/kqp/ut/indexes/kqp_indexes_fulltext_ut.cpp`)
- ✅ Added `InsertRow` test - verifies insert into table with basic fulltext index
- ✅ Added `InsertRowCovered` test - verifies insert into table with covered fulltext index
- ✅ Tests verify correct tokenization and index row generation

## Implementation Details

The implementation follows the same pattern as other KQP program builder methods:
- `TKqpProgramBuilder::FulltextAnalyze` creates a callable using `TCallableBuilder`
- Uses `FlatMap` to generate multiple index rows from a single input row (one per token)
- Properly handles serialization of analyzer settings for runtime execution
- Reuses existing `NKikimr::NFulltext::Analyze` function for consistency with index building
