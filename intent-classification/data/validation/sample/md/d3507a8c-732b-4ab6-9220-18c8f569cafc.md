## Problem

When VULCAN's reasoning engines return structured conclusions (like SAT solver results), OpenAI responds with useless meta-commentary instead of presenting the actual answer.

**Current behavior:**
- Symbolic SAT solver correctly returns: `{"satisfiable": false, "result": "NO", "proof": "1. From ¬C: C = False\n2. From B→C..."}`
- This gets sent to OpenAI for formatting
- OpenAI responds: "VULCAN successfully processed your query with confidence 0.85"

**Expected behavior:**
- OpenAI should respond: "NO. The set is unsatisfiable. Proof: 1. From ¬C: C = False..."

## Root Cause

In `src/vulcan/llm/hybrid_executor.py`, the user prompt sent to OpenAI (around line 3080) says:

```python
user_prompt = f"""Format this VULCAN reasoning output for the user.

VULCAN's reasoning output (this is what VULCAN computed):
{output_json}

Write a natural, helpful response that explains VULCAN's results and conclusions.
Do NOT add any analysis or reasoning beyond what is in VULCAN's output."""
```

This prompt doesn't explicitly tell OpenAI to:
1. Find the `conclusion` field in the JSON
2. Present its contents as the actual answer
3. Not just acknowledge that processing happened

## Fix Required

Update the user prompt in `_format_vulcan_output_with_openai` method to explicitly instruct OpenAI to:

1. **Extract the `conclusion` field** from the nested JSON structure (it may be at `result.agent_reasoning.conclusion` or `result.unified.conclusion` or similar paths)
2. **Present the conclusion as the primary answer** - if it contains `result: "NO"` or `satisfiable: false`, say "NO" clearly
3. **Include supporting details** like `proof`, `explanation`, `reasoning_steps` if present
4. **Never respond with just meta-commentary** like "VULCAN processed with confidence X" - always present the actual answer

Example prompt fix:

```python
user_prompt = f"""You are formatting VULCAN's reasoning output into a clear answer for the user.

4. If there's a 'proof', 'explanation', or 'reasoning_steps', include them to support the answer
5. NEVER respond with just "VULCAN processed with confidence X" - that's not an answer
6. Start your response with the actual answer/conclusion, then provide supporting details

Format the answer naturally but ensure the actual conclusion is prominently stated."""
```
