## Browser-Based YouTube Cookie Extraction

This PR implements a browser-based approach to extract YouTube cookies automatically, eliminating the need for manual cookie export.

### How It Works

1. **Start login session**: Run `ytcookies login` in Discord
2. **Connect remotely**: Open `chrome://inspect` in Chrome, add server:port, and click inspect
3. **Login to Google**: Complete the Google login in the remote browser window
4. **Save cookies**: Run `ytcookies save` to extract and save cookies to file

### New Files
- `src/utils/handlers/YouTubeCookieManager.ts` - Manages browser sessions and cookie extraction
- `src/commands/developers/YTCookiesCommand.ts` - Discord command for cookie management
- `.dockerignore` - Reduces Docker build context size by excluding node_modules, dist, cache, etc.

### Modified Files
- `Dockerfile` - Added Chromium and dependencies for headless browser
- `src/config/env.ts` - Added `enableBrowserLogin` config
- `optional.env_example` - Added browser login environment variables (all ports now configurable)
- `docker-compose.yaml` - Updated port mappings to use env variables

### New Environment Variables
- `ENABLE_BROWSER_LOGIN` - Enable/disable browser login feature (default: no)
- `BROWSER_DEBUG_PORT` - Port for Chrome remote debugging (default: 9222)
- `BROWSER_INSTRUCTIONS_PORT` - Port for the instructions page (default: 9223)
- `PUBLIC_HOST` - Public hostname/IP for accessing remote browser

### Commands
- `ytcookies status` - Show current cookie status
- `ytcookies login` - Start browser login session
- `ytcookies save` - Save cookies from active session
- `ytcookies cancel` - Cancel active login session
- `ytcookies clear` - Clear all stored cookies

### Security
- Feature is disabled by default
- Users are warned to use throwaway Google accounts
- Browser data is stored in `cache/browser-data/`
- Login sessions auto-expire after 10 minutes
- URL validation uses proper hostname parsing to prevent URL substring attacks
- Port validation ensures valid port range (1-65535)

### Docker Setup (if using browser login)
1. Add to your `.env`:
   ```
   ENABLE_BROWSER_LOGIN=yes
   BROWSER_DEBUG_PORT=9222
   BROWSER_INSTRUCTIONS_PORT=9223
   PUBLIC_HOST=your-server-ip
   ```
2. Uncomment ports in docker-compose.yaml:
   ```yaml
   ports:
     - "${BROWSER_DEBUG_PORT:-9222}:${BROWSER_DEBUG_PORT:-9222}"
     - "${BROWSER_INSTRUCTIONS_PORT:-9223}:${BROWSER_INSTRUCTIONS_PORT:-9223}"
   ```
