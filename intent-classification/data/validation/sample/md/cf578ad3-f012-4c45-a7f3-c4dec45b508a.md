## Changes

- **Tests**: Added assertions to `fontContext.test.ts` covering the new `analysisLangs` property.

```tsx
// SensesTextSummary now respects analysis language order

// ...

  sense.glosses.filter((g) => g.language === l).map((g) => g.def.trim())
);
```
