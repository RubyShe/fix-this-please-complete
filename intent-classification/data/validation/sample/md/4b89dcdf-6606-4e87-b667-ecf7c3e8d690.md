## Summary

This PR adds four new functions to `cavl2.h` as requested in the issue:

### New Functions

1. **`cavl2_predecessor(CAVL2_T* node)`** 
   - Returns the next smaller node in the in-order traversal of the tree
   - This is the opposite of `cavl2_next_greater()` 
   - Enables reverse in-order traversal: `for (CAVL2_T* p = cavl2_max(root); p != NULL; p = cavl2_predecessor(p))`
   - Time complexity: O(log n) for single call, O(n) for full traversal

2. **`cavl2_successor(CAVL2_T* node)`**
   - An alias for `cavl2_next_greater()` for naming consistency with `cavl2_predecessor()`
   - Time complexity: O(log n) for single call

3. **`cavl2_lower_bound(CAVL2_T* root, const void* user, cavl2_comparator_t comparator)`**
   - Finds the smallest node whose value is >= the search target
   - Similar to `std::lower_bound` in C++
   - Returns NULL if no such node exists (all nodes compare less than target)
   - Time complexity: O(log n)

4. **`cavl2_upper_bound(CAVL2_T* root, const void* user, cavl2_comparator_t comparator)`**
   - Finds the smallest node whose value is strictly > the search target
   - Similar to `std::upper_bound` in C++
   - Returns NULL if no such node exists (all nodes compare less than or equal to target)
   - Time complexity: O(log n)

### Tests Added

Comprehensive tests were added covering:
- Basic functionality of each new function
- Edge cases (NULL inputs, empty trees, boundary values)
- Full traversal verification (predecessor traverses in reverse order)
- Consistency verification (successor == next_greater)
- Lower/upper bound behavior for existing and non-existing values
- Complete boundary testing with 128 even values (0, 2, 4, ... 254) testing all 256 possible search targets

<pr_description>
Adds bound search and reverse traversal functions to cavl2.h.

## New Functions

- **`cavl2_predecessor(node)`** - Returns next smaller node in in-order traversal (inverse of `cavl2_next_greater`)
- **`cavl2_successor(node)`** - Alias for `cavl2_next_greater` for naming symmetry
- **`cavl2_lower_bound(root, user, comparator)`** - First node ≥ target (like `std::lower_bound`)
- **`cavl2_upper_bound(root, user, comparator)`** - First node &gt; target (like `std::upper_bound`)

All O(log n) per call.

## Example Usage

```c
// Reverse traversal
for (CAVL2_T* p = cavl2_max(root); p != NULL; p = cavl2_predecessor(p)) {
    // process nodes in descending order
}

// Range queries
CAVL2_T* first = cavl2_lower_bound(root, &min_key, comparator);  // first >= min_key
CAVL2_T* end   = cavl2_upper_bound(root, &max_key, comparator);  // first > max_key
```

## Tests

Comprehensive coverage including edge cases, NULL handling, and exhaustive boundary testing across 256 search targets against a tree of 128 even values.

/// Find the smallest node whose value is greater than or equal to the search target, in O(log n).
/// Returns the first node for which the comparator returns a non-positive result.
/// If no such node exists (all nodes compare less than target), returns NULL.
/// The comparator function returns: positive if target > candidate, zero if target == candidate, negative if target < candidate.
static inline CAVL2_T* cavl2_lower_bound(CAVL2_T* const          root,
                                         const void* const       user,
                                         const cavl2_comparator_t comparator)
{
    CAVL2_T* result = NULL;
    if ((root != NULL) && (comparator != NULL)) {
        CAVL2_T* n = root;
        while (n != NULL) {
            const CAVL2_RELATION cmp = comparator(user, n);
            if (cmp <= 0) {
                result = n;
                n      = n->lr[0];
            } else {
                n = n->lr[1];
            }
        }
    }
    return result;
}
