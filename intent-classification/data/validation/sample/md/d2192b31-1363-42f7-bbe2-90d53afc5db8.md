## Implementation Plan

### Goal
Add the ability for users to enable/disable individual tools during a chat session for apps that have tools configured.

### Implementation Steps

**1. Frontend Changes:**
- [x] Understand existing architecture
- [ ] Add `enabledTools` state to `useAppSettings` hook
- [ ] Save/load `enabledTools` in session storage
- [ ] Add tools selection UI in `AppConfigForm` component
- [ ] Pass `enabledTools` to chat API calls
- [ ] Add translations for new UI elements

**2. Backend Changes:**
- [ ] Modify `RequestBuilder` to accept `enabledTools` parameter
- [ ] Update `getToolsForApp` to filter by enabled tools
- [ ] Ensure tools are properly filtered before being sent to LLM

**3. Testing &amp; Validation:**
- [ ] Test with apps that have tools configured
- [ ] Verify tools can be enabled/disabled
- [ ] Ensure settings persist across sessions
- [ ] Test with different tool combinations

### Technical Details

The implementation will:
1. Add a new `enabledTools` array to app settings (stored in sessionStorage)
2. Default to all tools enabled (backward compatible)
3. Allow users to toggle individual tools on/off in the settings panel
4. Filter tools on the backend based on user selection
5. Provide a checkbox list UI similar to existing settings controls
