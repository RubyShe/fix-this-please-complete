### Gemmi API for finding `_vrf_*` keys
There is no dedicated prefix-filter API in gemmi; the fast approach is to iterate once over `block` pairs and collect keys that start with `_vrf`:
```python
vrf_keys = [item.pair[0] for item in self.block if item.pair and item.pair[0].startswith('_vrf')]
```
This is a single O(n) pass, which is already what `keys()`, `values()`, and `keys_with_essentials()` do.
