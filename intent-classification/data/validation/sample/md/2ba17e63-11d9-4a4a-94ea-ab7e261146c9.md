   - **After:** Clean string directly with simple replacements (remove origin, remove /static/js/ prefix, collapse whitespace)

4. **Updated `formatErrorForGA()`** - Now calls `formatStack(error)` directly instead of `formatStack(parseStackTrace(error))`

### Benefits

- **Removed 39 lines of code** (from 521 to 482 lines in error-capture.tsx)
- **Simpler logic** - Direct string manipulation instead of parse-then-format
- **No intermediate data structures** - Eliminates IStackFrame objects

- **All tests pass** - 23/23 tracking tests successful
- **Build successful** - Production build completes without errors
