<pr_title>
Refactor `STable` aggregation into headless `DataTableRoot`
</pr_title>

<pr_description>
This PR starts the table refactor by separating structural table primitives from the aggregated data-table behavior. The existing `STable` API remains the entrypoint, but the row/column rendering, selection, expansion, and slot orchestration now live in headless so later work can build on a single non-styled core.

- **What changed**
  - Added a new headless `DataTableRoot` that owns:
    - column filtering
    - cell value resolution by `dataIndex`
    - single/multi row selection state
    - expandable row state
    - header/body/footer rendering over one `<table>`
    - typed slot contracts for header, cell, selection, expand, and footer customization
  - Kept existing headless `Table*` components as pure structural primitives.

- **UI layer simplification**
  - Refactored `/src/components/table/table.vue` into a thin wrapper around `DataTableRoot`.
  - UI now focuses on:
    - variant/style injection via `provideTableUi`
    - default visual implementations for selection and expand controls
    - forwarding consumer slots to the headless core

- **API compatibility**
  - Preserved the current `STable` surface for:
    - column definitions
    - `selected` / `expanded` controlled state
    - selection and expandable rows
    - footer slot usage
    - existing dynamic header/cell slot patterns
  - Re-exported the new headless data-table types so downstream typing continues to work from the table package entrypoints.

- **Accessibility adjustments**
  - Added clearer built-in row labels for selection controls.
  - Disabled header selection when no rows are present.
  - Kept default selection/expand affordances overrideable through slots.

- **Foundation for next phases**
  - Introduces a dedicated headless aggregation layer without mixing it into the primitive `Table*` namespace.
  - Creates a better base for upcoming work on grouped headers, fixed columns, sorting/filtering, tree rows, and virtualization.

```vue

  <template #age="{ value }">

  </template>

  <template #expanded-row="{ row }">
    <div class="p-2">Expanded {{ row.name }}</div>
  </template>
</STable>
```

For single-selection mode (`multiple === false`), the default `<input type="radio">` uses `@change` to call `onSelectedChange(...)`.
