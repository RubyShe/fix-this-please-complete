ci(docs): auto-update hardware requirements disk sizes from sync CI
</pr_title>

<pr_description>
## Summary

Introduces an automated pipeline to keep the disk size figures on the <a href="https://docs.erigon.tech/get-started/hardware-requirements">Hardware Requirements</a> page up to date, removing the need for manual edits.

### How it works

1. **Measure** — `qa-sync-from-scratch` and `qa-sync-from-scratch (minimal node)` each run a `du -sb` step just before their cleanup, uploading a `disk-usage<chain><mode>.txt` artifact.
2. **Collect** — A new `update-disk-sizes.yml` workflow triggers via `workflow_run` on successful completion of either sync workflow, downloads all matching artifacts, and runs `docs/site/scripts/update-disk-sizes.py` to merge the bytes into `docs/site/src/data/disk-sizes.json`.
3. **Publish** — The workflow commits the updated JSON to `docs/auto/disk-sizes` and opens (or updates) a **draft PR** against `release/3.4` for human review before merging.
4. **Render** — `hardware-requirements.mdx` now imports `disk-sizes.json` and renders the *Current Disk Usage* column dynamically — no manual edits to the MDX needed after the first CI run.

### What is automated

| Network | Mode | Source |
|---------|------|--------|
| Ethereum mainnet | Full | `qa-sync-from-scratch` (weekly) |
| Ethereum mainnet | Minimal | `qa-sync-from-scratch (minimal node)` (nightly) |
| Gnosis Chain | Full | `qa-sync-from-scratch` (weekly) |
| Gnosis Chain | Minimal | `qa-sync-from-scratch (minimal node)` (nightly) |

### What is NOT automated yet — follow-up

**Archive mode** disk sizes require measurement from always-on snapshot machines rather than ephemeral CI runners (a full archive sync from scratch is impractical as a CI step). A follow-up PR will add this once snapshot machine access/outbound push is confirmed with the DevOps team.

The JSON also accepts `workflow_dispatch` with a custom `run_id` + `prune_mode`, so measurements can be triggered manually from any run.

| `docs/site/src/data/disk-sizes.json` | New data file (seeded with current Sept 2025 values) |
