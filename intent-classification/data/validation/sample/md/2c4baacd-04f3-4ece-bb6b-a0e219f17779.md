`install-windows.bat` failed because `greenlet>=1` — a conditional transitive dependency of SQLAlchemy (required on Windows/x86_64/aarch64) — was not reliably included in the offline wheels bundle. Silent `|| true` failures in the cross-platform `pip download` pass could leave only an incompatible or missing greenlet in `wheels/`.

## Changes

### `backend/pyproject.toml`
- Add `greenlet>=1.0.0` as an explicit direct dependency so it is always present in both `requirements.txt` and `requirements-windows.txt` and always downloaded.

### `scripts/build-mac-and-linux.sh`
- Replace direct `pyproject.toml` dep extraction with `uv pip compile`, generating **fully-pinned requirements files** (all transitive deps explicit) before the wheel download loop — no dep can be silently skipped.
- Use `--python-platform x86_64-pc-windows-msvc` when compiling Windows requirements so platform-conditional packages (e.g. `uvloop`) are correctly excluded.
- Add `win_arm64` to the wheel download platform list.
- Capture `uv pip compile` stderr and surface it on fallback instead of silently swallowing it.
- Replace `[[ ]]` bash-ism with POSIX `case` for platform routing.

### `.github/workflows/build.yml`
- Add `astral-sh/setup-uv@v5` to the `build-offline` job so `uv` is available for `uv pip compile` during CI builds.
