## Summary

The user reported that when the background was removed, frames were stacking on top of each other, causing "ghosts" of previous frames to be visible.

### Root Cause
When I set `renderer.setClearColor(0x000000, 0)` with alpha = 0, Three.js stopped automatically clearing the canvas between renders. This caused each new frame to render on top of the previous one, creating a ghosting effect.

### Solution Implemented
I added two key fixes to `render-template.html`:

1. **Set autoClear to true**: `renderer.autoClear = true` - Ensures the renderer's auto-clear feature is enabled
2. **Explicit canvas clearing**: Added `renderer.clear()` before each render in the `renderScene()` function - Forces the canvas to clear before rendering each frame

This ensures that each frame is rendered independently with a transparent background, without any ghosting artifacts from previous frames.
