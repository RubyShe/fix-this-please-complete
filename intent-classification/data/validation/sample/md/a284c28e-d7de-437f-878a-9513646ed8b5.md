<pr_title>
Fix missing array dimensions in QUBin sparse constructor calls
</pr_title>

<pr_description>
The QUBin parser used `sparse(I, J, V)` and `sparsevec(I, V)` without explicit dimensions, causing Julia to infer size from max indices. This produces wrong dimensions when variables have no linear/quadratic terms.

### Changes

- **`src/library/format/qubin/parser.jl`**: Pass dimension `n` (already read from file) to sparse constructors
  - `sparsevec(li, lv)` → `sparsevec(li, lv, n)`
  - `sparse(qi, qj, qv)` → `sparse(qi, qj, qv, n, n)`

- **`test/unit/library/formats.jl`**: Add test for model with 3 variables where variable 3 has no terms

### Example

```julia
# Model with n=3 but only terms for variables 1,2
li, lv = [1], [1.0]
qi, qj, qv = [1], [2], [2.0]

sparse(qi, qj, qv)        # (1, 2) matrix - wrong
sparse(qi, qj, qv, 3, 3)  # (3, 3) matrix - correct
```
