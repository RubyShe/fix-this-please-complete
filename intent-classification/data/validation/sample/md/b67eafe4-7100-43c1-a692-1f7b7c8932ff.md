User taps waypoint coordinates → callback updates HashMap entry for that waypoint ID → view refresh occurs → `fillViewHolder` retrieves position from HashMap → format preserved per waypoint.

- Cache/waypoint info sheets (map popups) - via `AbstractDialogFragment`

## Additional context

Logging added when invalid position values are corrected. JavaDoc documents API changes and parameter validation behavior. All implementations use consistent state management patterns.
