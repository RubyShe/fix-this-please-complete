</pr_title>

<pr_description>
This PR adds a comprehensive demo page for the Treebark plugin at `packages/web-deploy/json/features/11.treebark.idoc.json`.

## What's included

The demo showcases the key capabilities of the Treebark plugin through four interactive examples:

1. **Static Card Example** - Basic card component with inline data demonstrating the template structure
2. **Dynamic Card with Variables** - Interactive card with textbox and slider controls showing real-time data binding using calculated variables
3. **Data-Driven Cards** - Responsive grid of cards generated from an array using the `$bind` attribute to iterate over team member data
4. **Conditional Rendering** - Dynamic messages that change based on score values using the `$if` attribute

## Styling

Added 13 custom CSS rules for professional card presentation:
- Card components with shadows, borders, and rounded corners
- Badge indicators for active/inactive status
- Color-coded performance scores (green/yellow/red)
- Responsive CSS Grid layout for multi-card display
- Info boxes with accent borders

## Documentation

The demo includes a prominent link to the official Treebark documentation at https://danmarshall.github.io/treebark/ to encourage further exploration of the library's capabilities.
