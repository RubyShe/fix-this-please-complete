<pr_title>
Add Complete Soundex for Thai Words Similarity Analysis
</pr_title>

<pr_description>
### What does this changes

Implements Complete Soundex algorithm for Thai syllable phonetic encoding based on Chalermpol Tapsai, Phayung Meesad, and Choochart Haruechaiyasak. 2020. Complete Soundex for Thai Words Similarity Analysis. Information Technology Journal KMUTNB. 2020 June 30;16(1):46–59. paper. Pure algorithmic approach without hardcoded overrides. **Designed to work on individual Thai syllables - users must tokenize multi-syllable words first.**

**Usage:**
```python
from pythainlp.soundex import complete_soundex
from pythainlp.tokenize import syllable_tokenize

# Single syllable encoding
complete_soundex("ก้าน")  # 'กก1Bน2-'
complete_soundex("กลับ")  # 'กก1Aบ0ล'

# For multi-syllable words, tokenize first
syllables = syllable_tokenize("ปุญญา")  # ['ปุญ', 'ญา']
codes = [complete_soundex(syl) for syl in syllables]
result = ''.join(codes)  # 'ปป4G0น-ยย1B0--*'

# Via soundex engine parameter
from pythainlp.soundex import soundex
soundex("ทราย", engine="complete_soundex")  # 'ซซ1Bย0-'
```

### What was wrong

PyThaiNLP lacked the Complete Soundex algorithm for Thai phonetic similarity analysis despite its proven effectiveness in Thai NLP applications. Additionally, the initial implementation had bugs in format detection and incorrectly handled syllable tokenization internally. The main processing method also had high cyclomatic complexity, making it difficult to maintain.

### How this fixes it

**Core Implementation:**
- Initial consonant mapping with phonetic grouping (Table 5.1): 30+ consonants → 20 sound groups
- Vowel detection and encoding (Table 5.2): 15+ patterns including compound vowels (เอือ, เอีย)
- Final consonant normalization (Table 5.3): sonorant clustering rules
- Tone mark encoding (Table 5.4): 4 tone levels
- Special format for ญ/ย/น-initial syllables: tone-final position swap with asterisk marker for ญ

**Key Features:**
- **Syllable-level encoding**: Works on individual syllables without internal tokenization
- Context-aware cluster detection (ร/ล/ว) distinguishes phonetic clusters from syllable structure
- Syllable splitting heuristics handle multi-consonant patterns (อัตรา → อัต+ตรา)
- Special initial patterns (ทร → ซ sound)
- Dropped ร in final clusters with formatting (มารค → มม1B-ก0-)
- Pattern markers for ญญ/ญย/ณย compound syllables and ญ-initial syllables
- Special format rules:
  - Initial consonants ญ, ย, or น trigger tone-before-final format
  - Final consonant ญ or ณ triggers special format
  - Final consonant น with short vowel (1A) triggers special format

**Bug Fixes:**
- Fixed format detection for syllables ending in น with short vowels (ปัน → ปป1A0น-)
- Fixed format for syllables starting with น (นา → นน1B0--)
- Removed internal syllable_tokenize dependency to allow proper syllable-level encoding

**Code Quality Improvements:**
- Refactored complex `process_syllable` method into 10 focused helper methods to reduce cyclomatic complexity
- Each helper method has a single, clear responsibility for better maintainability
- Improved code readability while maintaining all functionality

**Documentation:**
- Module-level docstring with usage examples for single and multi-syllable words
- Function docstrings with tokenization guidance
- Test examples demonstrating recommended workflow with `word_tokenize()` and `syllable_tokenize()`

**Important Note:**
This soundex is designed to work on **individual Thai syllables**. For multi-syllable words, users should:
1. Tokenize text into words using `word_tokenize()`
2. Tokenize each word into syllables using `syllable_tokenize()`
3. Apply `complete_soundex()` to each syllable separately
