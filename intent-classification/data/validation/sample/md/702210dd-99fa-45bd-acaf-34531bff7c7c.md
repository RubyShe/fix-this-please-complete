This pull request refactors authentication authority handling in the MSAL token provider and simplifies JWT verification to better support multi-tenant, blueprint-based identity scenarios. The changes address issue #906, which identified problems with issuer validation and authority URL construction for blueprint identities that can be acquired in unpredictable tenant contexts.
