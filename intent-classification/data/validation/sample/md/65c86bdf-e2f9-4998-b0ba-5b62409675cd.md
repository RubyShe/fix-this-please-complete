```python
# These still raise as expected

\id MA           # too short (< 3 chars)
\id LUK          # mismatches text id MAT
```

- **Test data**: Updated `03LEVTes.SFM` (`\id Leviticus`) and `131CHTes.SFM` (`\id 1CH`) to exercise the new truncation path
- **Tests**: Added five new cases covering the above scenarios
