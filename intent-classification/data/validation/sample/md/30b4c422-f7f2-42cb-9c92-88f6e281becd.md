The `mark.calibre-search-match` CSS previously used hardcoded light yellow (`#fde68a`) and orange (`#f6ad55`) backgrounds with `color: inherit`. In dark mode the inherited text color is near-white (`#e2e8f0`), making highlighted text unreadable.

- **Dark**: dark amber bg (`#4a3000`) + warm yellow text (`#fde68a`); current: deeper amber bg (`#6b4400`) + amber outline

**2. History-based completion for the search input**

The sidebar search input now:
- Has a `<datalist id="calibre-search-history">` sibling element and uses `list="calibre-search-history"` with `autocomplete="on"`
- On page load, previously saved search terms are read from `localStorage` and populated into the datalist
- When a search is executed via Enter (first search or subsequent navigation), the term is saved to `localStorage` (capped at 50 entries, most-recent-first)
