Export CSS parser function and add CLI
</pr_title>

<pr_description>
Expose the CSS parsing logic as a standalone function and provide a CLI interface for parsing CSS without the PostCSS plugin.

## Changes

- **Exported `parse()` function**: Takes a CSS string, returns `Parsed` object with extracted tag/attribute/property metadata
- **Exported `Parsed` type**: Allows consumers to properly type the parse function output
- **Added CLI** (`src/cli.ts`): Uses `node:util.parseArgs`, reads CSS from stdin, outputs JSON
- **Updated exports**: Modified module exports to expose both the PostCSS plugin (default) and the parse function (named export)

## Usage

**Programmatic:**
```typescript
import { parse, Parsed } from 'mistcss';

const parsed: Parsed = parse('button[data-variant="primary"] { --color: blue; }');
// Returns: { button_data_variant_primary: { tag, attributes, properties, ... } }
```

**CLI:**
```bash
mistcss < input.css
# Outputs JSON representation of parsed CSS structure
```

The parse function reuses the existing selector parsing logic but operates on raw CSS strings rather than requiring PostCSS plugin integration.
