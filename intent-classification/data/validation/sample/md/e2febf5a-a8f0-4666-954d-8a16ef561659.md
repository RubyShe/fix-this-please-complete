<pr_title>
[charts] Refactor text measurement to use canvas-based implementation with letterSpacing support
</pr_title>

<pr_description>
## Overview

Refactors the text measurement utilities in `domUtils.ts` to use a canvas-based implementation when the environment supports `letterSpacing` correctly. This provides more accurate text measurements while maintaining backward compatibility through automatic fallback.

## Changes

### Canvas-Based Text Measurement
- Implemented `measureTextWithCanvas()` function that uses the HTML Canvas API for text measurements
- Canvas API provides more accurate measurements and better performance compared to DOM-based approaches
- Properly handles font styles including size, family, weight, style, and letterSpacing

### letterSpacing Support Detection
- Added `checkLetterSpacingSupport()` function that performs a one-time check on the first measurement
- Tests whether the browser's canvas API correctly applies letterSpacing to text metrics
- Caches the result to avoid repeated checks
- Gracefully handles environments where canvas is unavailable (e.g., jsdom test environment)

### Automatic Fallback
- Automatically falls back to the original SVG-based measurement when:
  - Canvas API is not available
  - letterSpacing is not supported by the canvas context
  - Any errors occur during canvas initialization
- Ensures measurements work in all environments without code changes

### Updated Functions
Both `getStringSize()` and `batchMeasureStrings()` now:
- Check for letterSpacing support on first call
- Use canvas measurement when supported
- Fall back to SVG measurement when not supported
- Maintain all existing caching behavior and API signatures

## Benefits

- **Better Accuracy**: Canvas API provides more precise text measurements, especially with letterSpacing
- **Improved Performance**: Canvas-based measurement is generally faster than DOM manipulation
- **Backward Compatible**: No breaking changes; existing code automatically benefits from improvements
- **Robust Fallback**: Works in all environments including test runners and older browsers

## Testing

- Added comprehensive test suite covering new functionality
- All 377 existing tests continue to pass
- Tests properly handle both jsdom and browser environments
- TypeScript compilation successful

## Example

```typescript
// Existing usage remains unchanged
const size = getStringSize('Hello World', { 
  fontSize: 16, 
  fontFamily: 'Arial',
  letterSpacing: 5  // Now properly measured with canvas when supported
});

// Batch measurements also benefit
const sizes = batchMeasureStrings(['Apple', 'Banana', 'Cherry'], {
  fontSize: 14,
  letterSpacing: 2
});
```

The implementation automatically detects browser capabilities and uses the best available method for text measurement.
