## Common Testing Issues and Fixes

### Issue: Tests Depend on Execution Order
```javascript
// Bad: Tests depend on shared state
let userId;
test('creates user', () => {
    userId = createUser();
});
test('updates user', () => {
    updateUser(userId);  // Depends on previous test!
});

// Good: Independent tests
test('creates user', () => {
    const userId = createUser();
    expect(userId).toBeDefined();
});
test('updates user', () => {
    const userId = createUser();  // Create own test data
    updateUser(userId);
});
```

### Issue: Testing Implementation Instead of Behavior
```javascript
// Bad: Testing implementation details
test('uses correct internal method', () => {
    const spy = jest.spyOn(service, 'internalMethod');
    service.publicMethod();
    expect(spy).toHaveBeenCalled();
});

// Good: Testing behavior
test('returns correct result', () => {
    const result = service.publicMethod();
    expect(result).toBe(expectedValue);
});
```

### Issue: Flaky Tests
```javascript
// Bad: Flaky test with timing issues
test('shows notification', () => {
    triggerNotification();
    expect(getNotification()).toBeVisible();  // May fail if not immediate
});

// Good: Wait for element
test('shows notification', async () => {
    triggerNotification();
    await waitFor(() => {
        expect(getNotification()).toBeVisible();
    }, { timeout: 3000 });
});
```

### Issue: No Assertions
```javascript
// Bad: Test without assertions
test('processes data', () => {
    processData(input);  // No assertion!
});

// Good: Test with assertions
test('processes data correctly', () => {
    const result = processData(input);
    expect(result.status).toBe('success');
    expect(result.data).toHaveLength(5);
});
```
