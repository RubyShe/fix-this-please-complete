<pr_description>

Fixed in commit 95dce967. The root cause was that `dist.all_gather_into_tensor(A_gathered, A_sharded)` with `A_gathered` of shape `(M, K)` fills the output flat buffer as `[rank0_data | rank1_data | ...]` in row-major order, which does **not** concatenate along K. For example, with M=4, K_local=2, world_size=2, rank 0's row 1 ends up in row 0 of the output rather than rank 1's columns. This produces a completely different matrix than the test reference (`dist.all_gather` + `cat(dim=1)`).

Fixed by replacing `all_gather_into_tensor` with `dist.all_gather(list, A_sharded)` + `torch.cat(list, dim=1)`, which correctly concatenates along K.
