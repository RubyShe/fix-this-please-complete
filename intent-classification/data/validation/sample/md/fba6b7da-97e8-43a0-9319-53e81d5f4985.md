## What *actually* works well in practice

### Recommended local → GitHub workflow

```bash
vendor/bin/phpstan analyse --error-format=json &gt; phpstan.json
```

Then:

* Use `jq` / script to:

  * Group by class
  * Strip noise
  * Generate TODOs
* Feed **that trimmed output** into Copilot
* Or generate:

  * Markdown checklist
  * Baseline file
  * PR comment

This is exactly what you were doing manually — just formalized.

---

## If your goal is “Copilot understands it”

Copilot works best with:

* **JSON**
* **Trimmed context**
* **Explicit instructions**

So your mental model is correct:

&gt; “PHPStan should have caught that”
&gt; → means **don’t show full traces, show intent**

PHPStan JSON + your prompt = best signal-to-noise ratio.
