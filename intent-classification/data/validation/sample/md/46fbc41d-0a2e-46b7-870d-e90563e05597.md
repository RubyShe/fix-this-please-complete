- In-memory backend recording invocations for dashboard visibility

```bash
# CLI usage
aws sagemaker-runtime invoke-endpoint \
  --endpoint-name my-endpoint \
  --body '{"data": "test"}' \
  --endpoint-url http://localhost:8000 \
  output.json
```

## Dashboard (`dashboard/sagemakerrumtime_handlers.go`)
- Invocations table showing operation, endpoint name, input/output previews, timestamp
- Code snippets for CLI, Go (`github.com/aws/aws-sdk-go-v2/service/sagemakerruntime`), and Python
- SageMaker Runtime operations rendered in the Docs page via `SageMakerRuntimeOps`

## Tests
- Unit tests for service handler (93.9% coverage)
- Dashboard handler tests (`dashboard/sagemakerrumtime_handlers_test.go`)
- E2E UI tests (`test/e2e/sagemakerrumtime_test.go`)
- Terraform fixture (`test/terraform/fixtures/sagemakerrumtime/success.tf`) and integration test (`TestTerraform_SageMakerRuntime`) verifying `InvokeEndpoint` via the `sagemakerruntime` SDK

## Wiring
- Registered in `cli.go` `getMostRecentServiceProviders()`
- `AWSSDKProvider` interface extended with `GetSageMakerRuntimeHandler()`
- Added to teststack and E2E test suite
