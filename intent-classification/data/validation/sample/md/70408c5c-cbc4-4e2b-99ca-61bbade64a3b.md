## Context

Prepares codebase for TanStack Start migration by decoupling from Next.js image optimization.

The new `OptimizedImage` component:
- Uses Netlify CDN in production via `process.env.NODE_ENV` check
- Defaults to webp format at quality 75 (optimized for performance)
- Leverages unpic's automatic `fetchpriority` and `loading` handling based on `priority` prop
- Supports `loading` prop for explicit lazy/eager loading control
- Supports all previous props including custom `operations`
- Maintains type safety with intentional `@ts-expect-error` for unpic's complex layout unions

**PageSpeed Optimizations Applied:**
- Reduced default image quality from 80 to 75 for better compression
- Added `priority` to header logo (above-fold, LCP candidate)
- Added `loading="lazy"` to footer badge (below-fold content)
- Used `layout="constrained"` for responsive hero image

**Integration Fixes:**
- Removed manual `fetchpriority` handling since unpic automatically sets `fetchpriority="high"` and `loading="eager"` when `priority={true}`
- Fixed console warning about non-boolean attributes
