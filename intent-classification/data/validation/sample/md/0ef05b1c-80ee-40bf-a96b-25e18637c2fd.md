<pr_title>
Add Arabizi transliteration with multi-candidate Arabic output and Quran word filtering
</pr_title>

<pr_description>
Arabizi (Arabic chat alphabet) is inherently ambiguous — digraphs like `sh` can map to ش or to س+ه — so a single-string output is insufficient. This adds Arabizi support that returns all possible Arabic interpretations, and integrates it into the QSE search pipeline as a replacement for Buckwalter.

## Changes

### `src/alfanous/romanization.py`
- **`ARABIZI2UNICODE`**: Single-character map covering digit-based sounds (`3→ع`, `7→ح`, `9→ص`, etc.) and common Latin letters (`s→س`, `h→ه`, `k→ك`, …). Fixed `e→ي` (vowel sound, not ع) and added `u→و`.
- **`ARABIZI_DIGRAPHS`**: Two-character sequences mapping to a single Arabic letter: `sh→ش`, `th→ث`, `kh→خ`, `dh→ذ`, `gh→غ`, `eh→ة` (ta marbuta for terminal feminine suffix).
- **`arabizi_to_arabic_list(string, ignore="")`**: Recursively explores all segmentations returning a deduplicated list of candidate Arabic strings, with enhanced rules:
  - **Rule A** (precedence): Multi-character codes processed before single characters.
  - **Rule B** (Al- prefix): Word-initial `el` or `al` generates a `ال`-prefixed candidate. Spaces reset the word-start flag so every word is handled independently.
  - **Rule C** (gemination): Doubled non-vowel consonants (e.g. `ll`, `tt`) generate an additional candidate with the letter followed by shadda (ّ). Vowels are excluded; digraph units are documented as distinct.
  - **Rule D** (vowel mapping): Initial `a` also yields `أ` (hamza-on-alef); terminal `a` also yields `ى` (alef maqsura); digraph `eh` yields `ة` (ta marbuta).
  - **Short vowel omission**: Every vowel (`a`, `e`, `i`, `o`, `u`) also yields an empty-string candidate, since short vowels are not written in unvocalized Arabic script (e.g. `salameh` → includes `سلامة`; `a5barak` → includes `اخبارك`, `أخبارك`).
- **`filter_candidates_by_wordset(candidates, wordset)`**: Shared utility that filters a candidate list to entries where every space-separated token exists in a given word set, falling back to all candidates if none match.

### `src/alfanous/paths.py`
- Added `WORD_FILE` path constant pointing to `word.json`.

### `src/alfanous/data.py`
- Added **`quran_unvocalized_words()`**: a `@lru_cache`-backed function that loads `word.json` and returns a `frozenset` of the 14 870 unvocalized Quranic word forms (`word_` field). Falls back to an empty frozenset on I/O errors so callers degrade gracefully.

### `src/alfanous/outputs.py`
- **Replaced Buckwalter with Arabizi for QSE**: When a query contains no Arabic characters, it is now treated as Arabizi. Candidates are generated with `arabizi_to_arabic_list()` and then filtered through `filter_candidates_by_wordset()` against `quran_unvocalized_words()`. If no candidates match the Quranic word list (e.g. dialect words), the full unfiltered candidate set is used as fallback. Arabic queries and field-qualified queries (containing `:`) pass through unchanged.

### `src/tests/test_engines.py`
- Replaced `test_advanced_search_buckwalter` with `test_advanced_search_arabizi`.
- Extended `test_arabizi_transliteration()` to cover short vowel omission (asserting `سلامة`, `اخبارك`, `أخبارك` appear in candidates).
- Added `test_arabizi_quran_word_filter()` using the shared `filter_candidates_by_wordset` utility, covering: Quran match (`يعطيك` from `ya36eek`), ta-marbuta match (`بكرة` from `bokreh`), and graceful fallback for non-Quranic dialect words.

## Example

```python
from alfanous.romanization import arabizi_to_arabic_list, filter_candidates_by_wordset

arabizi_to_arabic_list("sh")        # ['ش', 'سه']           — digraph vs. two letters
arabizi_to_arabic_list("el 7al")    # ['ال حال', 'يل حال']  — Rule B: el → ال
arabizi_to_arabic_list("ll")        # ['لّ', 'لل']           — Rule C: gemination
arabizi_to_arabic_list("salameh")   # [..., 'سلامة', ...]    — short vowel omission + eh → ة
arabizi_to_arabic_list("a5barak")   # [..., 'اخبارك', 'أخبارك', ...] — short vowel omission
arabizi_to_arabic_list("3la")       # ['علا', 'على']         — Rule D: terminal a → ى
arabizi_to_arabic_list("k*b", ignore="*")  # ['ك*ب']         — operator passthrough

from alfanous.data import quran_unvocalized_words
filter_candidates_by_wordset(arabizi_to_arabic_list("ya36eek"), quran_unvocalized_words())
# → ['يعطيك']  — filtered to the single Quranic match
```
