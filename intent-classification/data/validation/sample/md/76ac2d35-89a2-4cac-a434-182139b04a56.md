## Changes

**RequestAnimationFrame throttling**
- Pointer move events throttled to ~60fps via RAF (down from 100s+/second)
- Natural event coalescing: latest offset used, intermediate values discarded
- State cleanup on drag end prevents stale RAF callbacks

**Performance hints**
- `will-change: flex-basis` applied during drag, cleared on completion
- Allows browser to pre-optimize before layout changes occur

**CSS containment**
- `contain: layout style` on panels limits recalculation scope
- `contain: layout style paint` on resizers provides full isolation

**Deferred updates**
- ARIA attributes updated only on commit, not during drag
