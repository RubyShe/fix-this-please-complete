## Summary

**Problem:** When the "Add Backdrop" button is clicked and nodes are selected, the backdrop should be created around them.

**Change made:** In `GraphEditor.qml`, the "Add Backdrop" button's `onClicked` handler now:

1. **When nodes are selected:** Calculates the bounding box of all selected nodes:
   - Uses `node.x`/`node.y` for positions
   - Uses `node.nodeWidth`/`node.nodeHeight` with fallback to `uigraph.layout.nodeWidth`/`nodeHeight` for regular nodes (which return 0)
   - Adds `uigraph.layout.gridSpacing` (= 40px) as padding on all sides
   - Creates the backdrop at the top-left of the padded bounding box
   - Resizes it to cover the full padded area via `uigraph.resizeNode()`

2. **When no nodes are selected:** Keeps the existing behavior — creates the backdrop at the viewport center with default size.
