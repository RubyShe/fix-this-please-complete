<pr_title>
Implement sort filter with reverse, case_sensitive, and attribute parameters
</pr_title>

<pr_description>
Implements the full Jinja2 `sort` filter specification with all optional parameters and consolidated comparison logic.

## Summary

Created a shared `compareRuntimeValues` helper function that:
- Allows `None` values to be compared with `None` values (they are equal)
- Allows `Undefined` values to be compared with `Undefined` values (they are equal)
- Allows booleans to be compared with numbers (false=0, true=1)
- Allows integers and floats to be compared (both are numeric)
- Throws errors for incompatible type comparisons
- Handles `case_sensitive` option for string comparisons
- Returns -1, 0, or 1 for use with sort functions

Both `sort` and `dictsort` filters now use this shared helper for consistent comparison behavior.

## Changes Made

- **Sort filter enhancements**: Added support for `reverse`, `case_sensitive`, and `attribute` parameters
- **Positional argument support**: Matches Jinja2 API allowing both positional and keyword arguments
- **Dot notation support**: Added dot notation for nested attribute access (e.g., `"address.city"`)
- **Map filter enhancement**: Added dot notation support to the `map` filter
- **Fixed reverse filter mutation**: Array copies are created to avoid mutating original data
- **Extracted `getAttributeValue` helper**: Shared helper for dot notation attribute access

## Edge Cases Supported

- `{{ [None, None] | sort }}` → `[null, null]`
- `{{ [a, b, c] | sort }}` (undefined vars) → `[null, null, null]`
- `{{ [0, true, false, 1, 0.5] | sort }}` → `[0, false, 0.5, true, 1]`

## Examples

```jinja
{# Keyword arguments #}
{{ users | sort(attribute="name") }}
{{ users | sort(reverse=true, attribute="age") }}

{# Positional arguments (matching Jinja2) #}
{{ items | sort(true) }}  {# reverse #}
{{ items | sort(false, true) }}  {# case_sensitive #}
{{ users | sort(false, false, 'name') }}  {# attribute #}

{# Mixed positional and keyword #}
{{ users | sort(true, attribute='age') }}

{# Nested attributes with dot notation #}
{{ items | sort(attribute="details.priority") }}
```

## Testing

- ✅ 515 tests passing (1 network error expected)
- ✅ Linting passes
- ✅ Added comprehensive unit tests for all new functionality
