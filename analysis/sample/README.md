# Sample / labels

Holds the ask-type labels shared across RQ1–RQ3.

- `rq1_task_labels.csv`: the per-task **primary** ask-type labels assigned by the
  classifier over the full filtered population (`task_id, ask_type, ask_subtype`;
  324,695 rows). This is the label file consumed by the RQ2 and RQ3 scripts
  (`08`, `10`, `11`), produced by `scripts/07_rq1_task_labels.py`.

The manually coded validation sample (the 384 hand-labeled session-initiating asks,
the fixed random seed, the two coders' label columns, and the coding guides) is
distributed in the **separate manual-coding bundle**, together with the classifier
prompt and codebook. It is kept apart because it is hand-produced annotation material,
not generated by this pipeline.
